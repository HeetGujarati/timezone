毎日の朝会は十五分の同時開催の会合であり、全員が同じ時刻に机に着いているから成り立ちます。チームを四つの時間帯に広げれば、その前提は崩れます。たいていのチームは会合を動かして応じ、今度は別の誰かにとって具合が悪いと気づき、また動かします。

会合そのものが要点ではありません。要点は三つです。誰が何をしているか全員が把握できること、行き詰まりが一日以内に表に出ること、そして人々が一つのチームだと感じられること。三つとも会合なしで得られますし、ある広がりを超えたら会合なしで得るほかありません。

## まず自分たちの広がりを出す

チームの中で最も早い時間帯と最も遅い時間帯を取り、_今日の_日付で差を計算してください。記憶からではいけません。答えは動きます。ニューヨークとシドニーにまたがるチームは、北半球の冬に16時間、北半球の夏に14時間離れます。双方が正反対の季節に夏時間を採るからです。

次に、共通する09:00–18:00 の窓を探します。この数が形式を決めます。

| 共通の窓     | うまくいくもの                                                     |
| ------------ | ------------------------------------------------------------------ |
| 4時間以上    | 望むなら同時開催の朝会                                             |
| 2〜4時間     | 同時開催。ただしその窓は決定のためだけに守る                        |
| 2時間未満    | 書面の朝会と、週一回の同時開催の通話                                |
| なし         | すべて書面。加えて声が要る少数のために意図的な重なりを設ける        |

## 書面の朝会

現実との接触に耐える形式は、一人あたり短い書面の投稿を、_自分の一日の始まり_に、一つの共有された場所へ出すことです。

問いは三つ。

1. **終えたこと** — 「構文解析器をいじった」ではなく「構文解析器が入れ子の引用符を扱えるようになった。#482 に取り込み済み」
2. **次にやること** — 相手が自分の作業と重なるか判断できる程度に具体的に
3. **止まっている原因** — そして誰なら外せるのか、名指しで

価値があるのは三つめです。同時開催の朝会なら、行き詰まりはその十五分のうちに挙がって解決します。書面では、外せる人の名前が要ります。なければ丸一日の周回ぶん放置されます。

**一日の終わりではなく、始まりに投稿してください。** 一日の終わりに書いた投稿は、すでに自分の一日を終えた同僚に届きます。まるまる一周ぶんの余計な遅れです。始まりに書けば、あなたが起きるころ床に就く相手に届きます。それこそ望ましい引き継ぎです。

## 同時開催のまま残すもの

すべてを書くべきではありません。三つは本当に声が要ります。

- **本気の意見の相違をともなう決定。** 四往復しても収束していないやり取りは、五往復めでも収束しません。二十分の通話が終わらせます。
- **感情の重みがあるもの。** 指摘、対立、悪い知らせ。書面は調子を削ぎ落とし、読み手は最悪の調子を自分で補います。
- **まだ言葉にできない引っかかり。** 「この設計は何かおかしい気がするが、何かは言えない」は会話を要します。

それ以外 — 状況、進み具合、大半の質問、大半の決定 — は書いたほうが良い。書面は規模に耐え、声は耐えないからです。

## 週一回の通話を活かすには

広がりが六時間を超えたチームの多くは、週一回の同時開催に落ち着きます。自分の一日の外でそれを引き受ける人にとって割に合うようにするには。

**回してください。本気で。** いつも同じ地域が22:00 の枠を取るなら、それは持ち回りではなく序列です。

**特定の時間帯に固定し、どれかを明示してください。** 「木曜14:00 UTC」は曖昧さがなく、どこかの地域が時計を動かしてもずれません。「木曜午前9時、東部時間」はほかの全員にとって年に二度ずれ、しかも誰も身構えていません。

**議題を用意し、前日に送ってください。** 22:00 に参加する人には、それが割に合うかを知る権利と、始まる前に自分の関心事を加える権利があります。

**録音し、決定を書き起こしてください。** 出られない人は必ずいます。書き起こしが成果物であり、通話は手続きにすぎません。

## 失敗の型

**見えないずれ。** ある地域の現地時刻に固定された定例は、ほかの全員にとって年に二度一時間ずれ、誰も同意していない時刻に着地しかねません。UTC に固定するか、切り替えのたびに確認し直してください。

**膨れていく参加者一覧。** チームが三つの時間帯にいたころに決めた会合が、六つになったいまも続いており、新しい三つにとって時刻ははるかに悪い。動かそうと誰も言い出しません。動かすことは他人の不便だからです。参加者一覧を現在の広がりと突き合わせて年に二度見直してください。夏時間の日付がちょうどよい合図になります。

**誰も読まない書面の朝会。** 投稿が誰も開かない場所に落ちるなら、仕事を増やしたうえで会合の唯一の利点を取り除いたことになります。少なくとも初めのうちは、誰かが読んで応える必要があります。さもないと習慣は一か月で死にます。

**07:00 が06:00 になった件。** 誰かが一度、厚意で早朝の通話を引き受けました。それが恒久になり、やがて夏時間が一時間早め、誰も見直しませんでした。尋ねてください。

## 何を測るか

変更が効いたか確信が持てないなら、見る価値のある指標が三つあります。出席率はそのいずれでもありません。

**行き詰まりが解けるまでの時間。** 「詰まった」と言ってから誰かが応じるまでどれだけかかるか。同時開催の朝会なら数分です。よく運営された非同期のチームは半営業日を切ります。丸一日を超えるなら、その形式は失敗しています。

**週あたり、通話を要した決定の数。** これが増えているなら、書面の場が十分な背景を運べておらず、人々が既定で声に逃げています。

**誰が自分の勤務時間外に参加しているか、そしてどれくらいの頻度か。** 名前で記録してください。「面倒な枠は持ち回りにしている」が事実なのか願望なのかを教えてくれる数字です。

## 切り替えを始める

うまく切り替えるチームは、段階的にではなく一度に切り替える傾向があります。半分書面の朝会は、どちらの純粋な形よりも悪いからです。人は、書いておくべきことを言うために会合を待つようになります。

最後の同時開催の朝会を予告し、書面の形式と置き場所を合意し、判断を下す前に四週間続けてください。最初の二週間は接触が失われたように感じられます。実際そうだからです。毎日の通話のまわりの雑談には本当の価値があり、それは別の行き場を必要とします。専用の雑談用の場はその貧しい代用品ですが、それでも代用品ではあります。そうしない道は、それを保つために22:00 に起きていてくれと人に頼むことです。
