# ads.txt — Authorized Digital Sellers (IAB Tech Lab)
# https://iabtechlab.com/ads-txt/
#
# This file is deliberately empty of records.
#
# An ads.txt with no records is a positive statement, not an omission: it tells
# every buyer that NO seller is authorised to sell this domain's inventory. That
# is the truth today — the site carries no advertising, and any bid claiming to
# represent it is fraudulent. Serving the file with nothing in it is therefore
# safer than serving no file at all, which buyers read as "unknown" rather than
# "unauthorised".
#
# To enable advertising later, uncomment the line below and replace the two
# placeholders with the values your network gives you. The format is:
#
#   <exchange domain>, <publisher account id>, <DIRECT|RESELLER>, <certification id>
#
# The certification authority id is optional and network-specific; Google's is
# f08c47fec0942fa0. Get it from the network rather than copying it from another
# site — a wrong id invalidates the record silently.
#
google.com, pub-3451224240753943, DIRECT, f08c47fec0942fa0
#
# Three things have to happen in the same change, and DEPLOY.md lists them under
# "Enabling advertising": this file gains a record, PUBLIC_ADS_ENABLED is set to
# "true" so the slots and the consent banner render, and the cookie policy is
# updated *before* the first advertisement is served rather than after.
